# ERROR 07 원천

`raw-changes.csv`는 완료본 ZIP의 최종 ERROR 07 표에서 전사한 83바이트
실행 명령열, 실행되지 않는 11바이트 꼬리, 동적 목적지 피연산자 3개를
포함한 명시 source다. 따라서 97개 행을 쓰되, 실제 변경 바이트는 73개다.

꼬리의 문서 표기는 `0x3178→0x316B`로 반올림되어 있으나, 바로 앞 행의
명시 주소 `0x3176`과 원본 모듈의 1바이트 진행을 대조하면 실제 11바이트
범위는 `0x3175` down to `0x316B`다. 이 결정은 `input-provenance.json`에
기록했으며, 자동 주소 검색으로 대체하지 않는다.
