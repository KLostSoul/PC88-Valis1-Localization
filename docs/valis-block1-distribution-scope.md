# Block 1 배포 범위

이 저장소와 공개 압축본은 Block 1의 분석 결과를 기록하는 문서 저장소다. 원본 게임 이미지, ROM, D88, IPS, 중첩 패치 ZIP, 전체 번역표·글리프 시트·원문 대사와 이를 재현하는 대형 데이터는 포함하지 않는다.

공개하는 것은 직접 작성한 분석문서, 날짜별 계보·충돌 메타데이터, 공개본 내부 파일의 해시, 그리고 합법적으로 보유한 로컬 입력으로 후속 검증을 설계하기 위한 지침이다. 따라서 저장소의 ZIP은 실행 가능한 게임 패치나 원본 데이터의 대체물이 아니다.

이는 권리 확인 없이 원본·파생 게임 데이터를 공개 저장소로 옮기지 않기 위한 보수적 운영 기준이며, 특정 관할의 저작권 법률 자문이 아니다.
